# kp-toolkit

Выгрузка и анализ твоей библиотеки Кинопоиска: просмотренное, планы, оценки и красивый отчёт по вкусу.

Всё считается локально на твоём компьютере. Никуда ничего не отправляется, пароль скрипт не читает.

## Что умеет

- **`kp pull`** — открывает твой профиль Кинопоиска в браузере и сохраняет в CSV:
  - просмотренные фильмы/сериалы;
  - список «буду смотреть»;
  - оценки из раздела оценок (если Кинопоиск их не отдал прямо в списке).
- **`kp report`** — строит отчёт из этих CSV:
  - сводка, средняя и медиана;
  - распределение оценок с диаграммой;
  - все тайтлы по баллам;
  - жанры/типы с процентами «люблю» и «ненавижу»;
  - статистика по годам;
  - аниме отдельным блоком;
  - топ-20 и антитоп-20;
  - планы и просмотренное без оценки;
  - JSON-версия отчёта — удобно кидать в любую нейросеть.

## Установка

Нужен Python 3.10+.

```bash
cd kp-toolkit

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -e .
playwright install chromium
```

Если есть [uv](https://docs.astral.sh/uv/) — короче и быстрее:

```bash
uv venv
uv pip install -e .
uv run playwright install chromium
```

## Быстрый старт

```bash
kp pull --user ТВОЙ_ЛОГИН
kp report
```

`ТВОЙ_ЛОГИН` — это часть адреса профиля: `kinopoisk.ru/user/ЛОГИН/`.

После `pull` откроется браузер. Если Кинопоиск попросит войти — залогинься сам в окне браузера и нажми Enter в терминале. Дальше скрипт сам пройдёт по страницам.

Отчёты появятся тут:

```
data/report.txt    # читаемый отчёт
data/report.json   # тот же отчёт в JSON
```

## Команды

### `kp pull`

```
kp pull --user ЛОГИН            # базовый вариант
kp pull --user ЛОГИН --dir data # своя папка для данных
kp pull --user ЛОГИН --skip-votes  # только списки, без оценок
kp pull --user ЛОГИН --votes-user 123456  # если адрес страницы оценок отличается
```

| Флаг | Зачем |
| --- | --- |
| `--user` | логин профиля в адресе Кинопоиска (обязательный) |
| `--votes-user` | ID, если страница оценок открывается только по нему |
| `--dir` | куда сохранять CSV (по умолчанию `data`) |
| `--skip-votes` | не ходить по странице оценок, только списки |

### `kp report`

```
kp report
kp report --dir data
```

Без `pull` работает только если CSV уже есть.

Вместо `kp` можно писать `python -m kp_toolkit` — это то же самое.

## Что лежит в `data/`

| Файл | Что внутри |
| --- | --- |
| `kinopoisk_watched.csv` | просмотренное (название, год, оценка, ссылка) |
| `kinopoisk_planned.csv` | «буду смотреть» |
| `kinopoisk_ratings.csv` | оценки из раздела оценок |
| `kinopoisk_watched_with_ratings.csv` | просмотренное, склеенное с оценками |
| `report.txt` / `report.json` | отчёт |
| `.kp-browser/` | профиль браузера с твоей сессией |

Папка `data/` и профиль браузера добавлены в `.gitignore` — в репозиторий они не уедут.

## Как это работает

Официального публичного API у Кинопоиска нет, поэтому данные берутся из твоего же аккаунта: Playwright открывает твои страницы профиля, а из HTML достаются названия, годы и оценки.

Что важно:

- **логин и пароль вводишь только сам** в окне браузера, скрипт их не видит и не сохраняет;
- между страницами есть пауза, при HTTP 429 скрипт ждёт и повторяет запрос — без спама;
- названия вида `Форма голоса 2016, аниме` разбираются на чистое название, год и тег, поэтому жанры и аниме в отчёте настоящие, а не догадки;
- селекторы эвристические: если Кинопоиск поменяет вёрстку, выгрузка может начать терять поля — тогда проще открыть issue или поправить JS в `kp_toolkit/scraper.py`.

## Если что-то пошло не так

**Отчёт говорит, что CSV не найден.**
Сначала выполни `kp pull --user ЛОГИН`. Файлы должны лежать в папке, указанной в `--dir`.

**Оценки не выгрузились.**
Список просмотренного сохранится в любом случае, просто отчёт будет без оценок. Проверь, открывается ли страница оценок вручную; попробуй `--votes-user` с числовым ID профиля.

**Выгрузка остановилась на середине.**
Перезапусти `kp pull` — уже сохранённые страницы никуда не денутся, скрипт начнёт заново и допишет недостающее в те же CSV.

**Вылезла капча или страница входа.**
Залогинься в окне браузера руками и нажми Enter в терминале.

## Приватность

CSV с твоими оценками и профиль браузера остаются на твоей машине. Если решишь поделиться отчётом с друзьями — `report.txt` можно просто переслать, в нём только названия и твои оценки.
