# kp-toolkit

> CLI-инструмент для экспорта и анализа твоей библиотеки Кинопоиска.

`kp-toolkit` собирает твои списки прямо из твоего аккаунта Кинопоиска — просмотренное, «буду смотреть» и оценки — и строит по ним понятный отчёт с распределением оценок, статистикой по жанрам и годам, топами и блоком про аниме.

Всё считается локально на твоём компьютере. Ничего никуда не отправляется, и пароль ты вводишь только сам в окне браузера — скрипт его не видит.

## Возможности

- **Выгрузка просмотренного** — фильмы и сериалы с годами, оценками и ссылками.
- **Планы** — список «буду смотреть».
- **Оценки** — из раздела оценок аккаунта (если Кинопоиск не отдал их прямо в списке).
- **Отчёт** — сводка, средняя и медиана, распределение оценок с диаграммой, все тайтлы по баллам, жанры и типы с процентом «люблю» (9–10) и «ненавижу» (1–5), статистика по годам, топ-20 и антитоп-20, отдельный блок по аниме, просмотренное без оценки и планы.
- **JSON-выгрузка** — тот же отчёт в `report.json`: удобно передавать в любую нейросеть или анализировать скриптом.
- **Локальная обработка** — все CSV и отчёты остаются на твоей машине.
- **Безопасный вход** — браузерная аутентификация: ты логинишься сам в окне браузера, скрипту твой пароль не нужен.

`kp report` генерирует `report.txt` примерно такого вида (данные синтетические):

```

С оценкой:       20
Без оценки:      5
В планах:        12
Средняя оценка:  7.90
Медиана:         8.0
Оценки 9-10:     40.0%
Оценки 1-5:      5.0%
Аниме:           4 шт., средняя 8.50

2. РАСПРЕДЕЛЕНИЕ ОЦЕНОК
10 | ████████████████████················   5  (25.0%)
 9 | ███████████·························   3  (15.0%)
```

## Требования

- Python 3.10+ (проект разрабатывается на 3.12).
- Для выгрузки (`kp pull`) — Chromium через Playwright (ставится одной командой, см. ниже).
- Для построения отчёта из уже готовых CSV — только Python, браузер не нужен.

## Установка

### Через uv (рекомендуется)

```bash
cd kp-toolkit
uv venv
uv pip install -e .
uv run playwright install chromium
```

### Через pip

```bash
cd kp-toolkit
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -e .
playwright install chromium
```

После установки появляется команда `kp`. Это то же самое, что `python -m kp_toolkit`.

## Быстрый старт

```bash
kp pull --user ТВОЙ_ЛОГИН
kp report
```

`ТВОЙ_ЛОГИН` — это часть адреса твоего профиля: `kinopoisk.ru/user/ЛОГИН/`.

Во время `kp pull` откроется окно браузера. Если Кинопоиск попросит войти — залогинься сам в окне и нажми Enter в терминале. После этого скрипт пройдёт по страницам и сохранит CSV. Дальше `kp report` соберёт из них отчёт.

Отчёты появятся в папке `data/`:

- `data/report.txt` — читаемый отчёт;
- `data/report.json` — тот же отчёт в JSON.

## Команды

### `kp pull`

Выгрузка данных из профиля Кинопоиска:

```
kp pull --user ЛОГИН                      # базовый вариант
kp pull --user ЛОГИН --dir mydata         # своя папка для данных
kp pull --user ЛОГИН --skip-votes         # только списки, без оценок
kp pull --user ЛОГИН --votes-user 123456  # если адрес страницы оценок отличается
```

| Флаг | Значение |
| --- | --- |
| `--user` | логин профиля в адресе `kinopoisk.ru/user/ЛОГИН/` (обязательный) |
| `--votes-user` | ID, если страница оценок открывается только по нему |
| `--dir` | папка для данных (по умолчанию `data`) |
| `--skip-votes` | не ходить по странице оценок, только списки |

### `kp report`

Построение отчёта из уже выгруженных CSV:

```
kp report
kp report --dir mydata
```

Без `pull` работает только если CSV уже лежат в указанной папке.

Каждая команда подробнее описывает себя: `kp --help`, `kp pull --help`, `kp report --help`.

## Выходные файлы

Папка с данными (по умолчанию `data/`):

| Файл | Что внутри |
| --- | --- |
| `kinopoisk_watched.csv` | просмотренное: название, год, оценка, ссылка |
| `kinopoisk_planned.csv` | «буду смотреть» |
| `kinopoisk_ratings.csv` | оценки из раздела оценок |
| `kinopoisk_watched_with_ratings.csv` | просмотренное, склеенное с оценками |
| `report.txt` | читаемый отчёт |
| `report.json` | отчёт в JSON |
| `.kp-browser/` | профиль браузера с твоей сессией |

Исходные CSV и сгенерированные отчёты находятся только внутри этой папки и в git не попадают.

## Аутентификация и приватность

Официального публичного API у Кинопоиска нет, поэтому данные берутся из твоего же аккаунта: Playwright открывает твои страницы профиля и извлекает из HTML названия, годы и оценки.

- **Логин и пароль вводишь только ты** — в окне браузера. Скрипт их не читает и не сохраняет.
- Сессия хранится в `data/.kp-browser/` и остаётся на твоей машине.
- Всё считается локально; ни CSV, ни отчёты никуда не отправляются.

## Как это работает

- **`kp pull`** открывает профиль в браузере и сохраняет страницы списков в CSV. Между страницами есть пауза, а при HTTP 429 скрипт ждёт и повторяет запрос — без спама.
- Названия вида `Форма голоса 2016, аниме` разбираются на чистое название, год и тег, поэтому жанры и аниме в отчёте настоящие, а не догадки.
- Селекторы эвристические: если Кинопоиск поменяет вёрстку, выгрузка может начать терять поля — тогда проще открыть issue или поправить JS в `kp_toolkit/scraper.py`.

## Тестирование

Тестов в репозитории нет — они были удалены, чтобы не хранить даже синтетические названия, совпадавшие с личной библиотекой. Проверка корректности выполняется локально: после выгрузки CSV запусти `kp report` и посмотри отчёт. CI ограничен простыми smoke-проверками (импорт + `--help`).
