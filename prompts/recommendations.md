Сформируй **персонализированные рекомендации** на основе только отчёта пользователя (`report.txt`/`report.json`). Не бери в расчёт популярность, рейтинги Кинопоиска в целом или хайп.

## Главная задача
**Подобрать небольшую подборку (10–15) тайтлов, которые с наибольшей вероятностью зайдут именно этому пользователю, с объяснением ПОЧЕМУ.**

## Принцип работы

1. **Сначала выведи вкусовой профиль.** Коротко опиши ключевые паттерны по любимым работам (качества, темы, атмосфера, баланс, персонажи), которые будешь использовать для подбора.
2. **Сравнивай по качествам, а не по жанру.** Не предлагай «ещё одно аниме», просто потому что много аниме в топе. Предлагай то, что **похоже по принципу воздействия**, а не по ярлыку.
3. **Учитывай и фильмы, и сериалы, и аниме** в меру, если они органично вписываются в выявленные паттерны.
4. **Смотри на планы.** Если в отчёте есть `planned`/«буду смотреть», **не предлагай их заново**. Либо не упоминай, либо коротко прокомментируй, почему они логичны.
5. **Не предлагай уже просмотренные.** Исключи всё, что есть в просмотренном списке.

## Требования к рекомендациям

Для **каждого** тайтла дай:
- **Название** (желательно с годом)
- **Формат** (фильм/сериал/аниме)
- **Короткое обоснование** — какие именно наблюдаемые предпочтения он отражает (2–4 предложения максимум)
- **Соответствие паттернам** — 1–2 конкретных качества из профиля, с которыми он совпадает
- **Уровень уверенности**: `высокий` / `средний` / `экспериментальный`
- **Почему может не зайти** (кратко) — только если есть осмысленное предположение

## Правила подбора

- **Делай упор на доказательства.** Каждая рекомендация должна опираться на **конкретные** черты из высоко оценённых работ пользователя.
- **Разделяй уверенность.** Не обещай, что «точно понравится». Чётко обозначай степень уверенности.
- **Меньше, но осознаннее.** 10–15 тайтлов — оптимально. Лучше 12 хорошо обоснованных, чем 30 слабых.
- **Учитывай антипрофиль.** Избегай тайтлов с паттернами, которые систематически не заходят пользователю.
- **Не выдумывай редкие гипотезы.** Если не можешь связать рекомендацию с 1–2 явными качествами из данных — не предлагай её.
- **Ставь на «близкое по ощущениям», а не «однотипное».** Фокус на атмосфере, темпе, типе истории, а не на жанровом клоне.

## Формат ответа

Сначала **краткий вкусовой профиль** (3–5 пунктов). Затем **список рекомендаций** по пунктам с полным описанием по требованиям выше. В самом конце — короткое резюме: что объединяет всю подборку.
