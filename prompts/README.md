# Prompts для анализа отчёта Kinopoisk

Эти файлы — готовые промпты для LLM (ChatGPT, Claude, Gemini и др.). Их можно копировать вместе с сгенерированным отчётом и отправлять модели для персонального анализа вкуса.

## Как пользоваться

1. Сначала сгенери отчёт:
   ```bash
   kp report
   ```
2. Возьми один из промптов (например, `taste.md`) и сгенерированный отчёт (`data/report.txt` или `data/report.json`).
3. Скопируй промпт + прикрепи/вставь отчёт в чат с LLM.
4. Начни с `taste.md` для общего обзора, затем используй специализированные промпты при желании.

**Рекомендуется** передавать именно сгенерированный отчёт (`report.txt`/`report.json`), а не сырые CSV: он компактнее, нормализован и содержит всю необходимую сводку.

Промпты независимы друг от друга. Каждый можно использовать отдельно. Дополнительных инструментов/установки не требуется.

## Доступные промпты

| Файл | Для чего |
|---|---|
| `taste.md` | Общий анализ вкуса: что я люблю смотреть и почему |
| `anime.md` | Анализ вкуса в аниме |
| `movies.md` | Анализ полнометражных фильмов |
| `series.md` | Анализ сериалов (отдельно от фильмов) |
| `dislikes.md` | Антипрофиль: что точно не нравится |
| `recommendations.md` | Практические рекомендации с обоснованием и уровнем уверенности |
| `profile.md` | Легкая интерпретация в виде «какой я зритель» |
| `deep-dive.md` | Самый подробный структурированный анализ всего сразу |
